# TRIGGZ // AI CODE LAB

A cyber-dark, multi-platform AI IDE and creative coding companion. Generate and edit multi-file projects, preview HTML/JS live, and export your work as a ZIP bundle.

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Included

- Monaco editor workspace with multi-file project state
- HTML/JavaScript/CSS live preview in a sandboxed iframe
- One-click ZIP export
- Persona-driven AI sidebar UI with local conversation state
- Cyberpunk responsive IDE layout

The sidebar currently exposes an AI-provider seam in the UI; connect your preferred model API through a server route before sending production prompts.
